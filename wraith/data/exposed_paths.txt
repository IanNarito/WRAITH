# Sensitive-file wordlist for the exposed_files check.
#
# Format (one entry per line, fields separated by " | "):
#   path | severity | flags | title | signature
#
# signature  Python regex matched against the raw response BYTES (so binary magic numbers like
#            \x1f\x8b work). A file is reported only if the response is 200 and the signature
#            matches: this content verification is what keeps false positives out.
# flags      "-" or "html". Without "html", responses that are HTML documents are ignored, so
#            catch-all pages and soft 404s cannot match.

# Version control
/.git/HEAD | high | - | Git repository exposed | ^(ref: refs/|[0-9a-f]{40}\s*$)
/.git/config | high | - | Git repository config exposed | (?m)^\s*\[(core|remote "[^"]*")\]
/.svn/entries | high | - | Subversion working copy exposed | ^(\d+\s*\n|<\?xml[^>]*>\s*<wc-entries)
/.svn/wc.db | high | - | Subversion working copy database exposed | ^SQLite format 3\x00
/.hg/requires | high | - | Mercurial repository exposed | (?m)^(revlogv1|store|fncache|dotencode)\s*$
/.bzr/branch-format | high | - | Bazaar repository exposed | Bazaar
